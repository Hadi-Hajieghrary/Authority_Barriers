\begin{abstract}
A cable-suspended payload may approach a wall while every cable pulls it toward the wall. Although a high-order control barrier function (HOCBF) can admit an input now, the filter can lose feasibility before a quadrotor has time to swing behind the payload. We give a conditional, open-set certificate for this failure and a two-quadrotor example. A thrust-reserved maneuver yields a stopping-distance barrier whose safe set is controlled invariant for the continuous-time taut-cable model. An optimistic stopping distance bounds the viability kernel from outside. Both distances use the cable-direction-dependent support function of a tension zonotope. Simulations expose substantial conservatism when swinging is required, and wall contacts under a sampled filter and slack-cable model. These results distinguish the continuous-time certificate from its unverified sampled implementation.
\end{abstract}
